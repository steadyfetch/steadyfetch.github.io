# steadyfetch.github.io

Honest comparison pages for Steadyfetch's data actors on Apify: one page per family (ad transcripts, Google Trends and keywords, jobs, Amazon, YouTube and media), listing every competing actor and the main vendors next to ours with the same price columns.

Static HTML. `node build.mjs` regenerates every page from the data at the top of the script; prices carry the date they were read. Live at https://steadyfetch.github.io/.
